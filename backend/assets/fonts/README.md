# Document fonts

Fonts bundled into the backend image for result documents (E7). The renderer
uses only these (`--ignore-system-fonts`), so every school's PDFs look the
same and Bangla is shaped correctly.

| Files | Font | Source | Licence |
|---|---|---|---|
| `NotoSansBengali-*.ttf` | Noto Sans Bengali, static, hinted | notofonts/notofonts.github.io (`fonts/NotoSansBengali/hinted/ttf`) | SIL OFL 1.1, `OFL-NotoSansBengali.txt` |
| `NotoSans-*.ttf` | Noto Sans, static, hinted | notofonts/notofonts.github.io (`fonts/NotoSans/hinted/ttf`) | SIL OFL 1.1, `OFL-NotoSans.txt` |

`SHA256SUMS` records the files as added.
